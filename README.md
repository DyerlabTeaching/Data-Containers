## Impetus

We rarely work with a single datum; instead, we work with large volumes of data. As such, we need to be adept at handling large volumes of data, understanding how it is stored, and working with it efficiently. In this topic, the basics of the following container types are explored.

- Vectors
- Matrices
- Lists
- Data Frames

## Module Learning Objectives

### Apply and Analyze Data Container Structures

> Learners will correctly construct and manipulate core R data containers (vectors, matrices, lists, and data frames), and evaluate when each structure is most appropriate for storing and analyzing population genetic data.

- **Bloom's Levels:** Apply (construct, manipulate), Analyze (distinguish, evaluate)
- **Reinforces:** Provides the structural vocabulary (vectors, matrices, lists, data frames) that every later module's code depends on.
- **Notes:** Evaluating *when* each structure is appropriate is emphasized as much as building one.

### Integrate Data Containers into Reproducible Workflows

> Learners will import, access, update, and export data across multiple container types, developing analysis-ready R objects that support downstream population genetic workflows.

- **Bloom's Levels:** Apply (import, edit, export), Create (develop workflow-ready structures)
- **Reinforces:** Connects raw container mechanics to the import/export patterns used throughout Tidyverse, Joins, and every subsequent data-driven module.
- **Notes:** Frames containers not as an abstract data-structures lesson but as the entry point into real analysis pipelines.
